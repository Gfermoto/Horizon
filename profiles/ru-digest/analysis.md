# Цель оценки

Оцени, насколько свежая технологическая новость важна для русскоязычного канала о технологиях, AI, железе и open source.

# Шкала

- **9–10: Прорыв.** Крупные научные или инженерные результаты, смена парадигмы, значимые релизы широко используемых технологий, решения, меняющие рынок.
- **7–8: Высокая ценность.** Важные события, которые стоит опубликовать сразу: технические разборы, новые подходы, полезные инструменты, значимые обновления.
- **5–6: Интересно.** Постепенные улучшения, полезные, но не срочные новости, умеренный интерес аудитории.
- **3–4: Низкий приоритет.** Рутинные обновления, поверхностные материалы, заметный маркетинг.
- **0–2: Шум.** Спам, офтоп, тривиальные обновления, чистая реклама.

# Указания

Учитывай техническую глубину, новизну, вероятное влияние, качество источника, релевантность для русскоязычной аудитории и конкретные детали. Не путай популярность с важностью. Не вознаграждай кликбейт. Для китайских источников оценивай значение для глобального рынка и объяснимость для русского читателя.

Верни 3–5 конкретных тегов темы.
