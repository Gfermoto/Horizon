# Профиль «Русский дайджест»

Используй этот профиль для свежих технологических и AI-новостей, которые нужно превратить в короткий русский пост для Telegram-канала.

Подходит для релизов, исследований, продуктовых анонсов, инцидентов, изменений в железе, open source и индустрии. Не подходит для длинных авторских колонок, пошаговых туториалов, академических статей целиком, финансовой аналитики и рекламы без фактов.
